`INTAKE → AUTHORIZE → HYDRATE → EXECUTE/DRAFT → VALIDATE → EVIDENCE → HANDOFF/COMPLETE`

## Dynamic tools
When a newly connected MCP/tool is assimilated, use it only after its capability record is mapped to this team and its trust state permits the requested operation. Read capability descriptions/schema from the adaptive registry; never infer authority from tool availability.

## Self-start rule
A job may self-start only when it is linked to an active goal/mission and triggered by a permitted event or schedule. Consequential actions still pass the policy gate.

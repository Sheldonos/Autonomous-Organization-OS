# Buyer Security & Governance Summary

- No customer credentials ship in the release.
- New MCP/tool capabilities begin quarantined.
- Tool availability never grants authorization.
- Consequential actions pass global policy and decision-right gates.
- Production writes require a certified connector path and observable read-back.
- Mission, job, approval and evidence state are persisted outside conversational memory.
- Generated self-improvements do not silently rewrite the production core.
- The release preserves source provenance and requires upstream license review before public redistribution of user-provided/upstream-origin material.

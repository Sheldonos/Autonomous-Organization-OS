# Cross-Pocket Mission Examples

1. **Create a company from a new thesis** → ResearchOS → VentureOS → BuildOS → LaunchOS → RevenueOS → DealOS → CapitalOS.
2. **Win a major RFP** → DealOS → ResearchOS → BidOS → PricingOS → LegalOS → ConsultingOS/BuildOS → CustomerOS.
3. **Launch a creator commerce business** → CreatorOS → BrandOS → MediaOS → CommerceOS → RevenueOS → DealOS.
4. **Acquire a strategic capability** → ResearchOS → CorpDevOS → M&A OS → CapitalOS → LegalOS → RiskOS → PMO OS.
5. **Reduce enterprise cyber exposure** → EnterpriseOS → SecurityOS → RiskOS → ComplianceOS → BuildOS → ExecutiveOS.
6. **Commercialize dormant IP** → PatentOS → Patent-to-ProductOS → ResearchOS → VentureOS → PartnershipOS/DealOS.
7. **Operate an accelerator** → AcceleratorOS → LearningOS → VentureOS → FundraiseOS → DealOS.
8. **Optimize procurement and supply** → ProcureOS → VendorOS → SupplyOS → RiskOS → LegalOS → PricingOS.
9. **Run a media company** → ResearchOS → MediaOS → BrandOS → CreatorOS → RevenueOS → DealOS.
10. **Align workforce to strategy** → EnterpriseOS → TalentOS → WorkforceOS → RecruitOS → LearningOS → ExecutiveOS.

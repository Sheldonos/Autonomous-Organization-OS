# LabOS

**Mission:** Operate R&D programs with hypotheses, experiments, evidence, reproducibility, and portfolio decisions.

## Operating loop
1. Research question
2. Protocol & safety review
3. Experiment planning
4. Execution tracking
5. Data capture
6. Analysis
7. Replication & critique
8. Research decision & knowledge capture

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate labos` to materialize only those skill packages into a working directory.

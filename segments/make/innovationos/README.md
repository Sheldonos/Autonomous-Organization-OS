# InnovationOS

**Mission:** Continuously discover, evaluate, incubate, and scale strategic innovations.

## Operating loop
1. Signal sensing
2. Opportunity thesis
3. Strategic fit scoring
4. Experiment design
5. Prototype
6. Evidence review
7. Portfolio decision
8. Scale or sunset

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate innovationos` to materialize only those skill packages into a working directory.

researchos, ventureos, buildos, capitalos

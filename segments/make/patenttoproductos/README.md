# Patent-to-ProductOS

**Mission:** Find valuable intellectual property and convert it into validated products, licenses, ventures, or partnerships.

## Operating loop
1. IP discovery
2. Claim and landscape review
3. Market mapping
4. Commercial fit
5. Prototype or license strategy
6. Partner discovery
7. Deal structure
8. Commercialization tracking

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate patenttoproductos` to materialize only those skill packages into a working directory.

## Handoffs
patentos, researchos, ventureos, partnershipos, dealos

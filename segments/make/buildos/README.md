# BuildOS

**Mission:** Translate product intent into secure, tested, deployed, observable software and digital systems.

## Operating loop
1. Product requirements
2. Architecture
3. Work decomposition
4. Implementation
5. Automated testing
6. Security review
7. Release & deployment
8. Telemetry & repair

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate buildos` to materialize only those skill packages into a working directory.

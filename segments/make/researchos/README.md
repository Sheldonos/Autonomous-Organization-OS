# ResearchOS

**Mission:** Convert questions into evidence-grounded findings, scenarios, decisions, and reusable knowledge.

## Operating loop
1. Question decomposition
2. Source plan
3. Evidence collection
4. Source quality & contradiction review
5. Analysis & modeling
6. Scenario simulation
7. Synthesis
8. Decision packet & provenance

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate researchos` to materialize only those skill packages into a working directory.

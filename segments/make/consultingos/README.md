# ConsultingOS

**Mission:** Run evidence-driven consulting engagements from discovery through implementation and outcome measurement.

## Operating loop
1. Engagement charter
2. Discovery
3. Data & interview intake
4. Diagnosis
5. Benchmarking
6. Solution design
7. Executive deliverable
8. Implementation PMO
9. Outcome measurement

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate consultingos` to materialize only those skill packages into a working directory.

## Handoffs
researchos, pmoos, buildos, revenueos

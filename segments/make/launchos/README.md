# LaunchOS

**Mission:** Coordinate a cross-functional product, service, or market launch from readiness through post-launch learning.

## Operating loop
1. Launch charter
2. Dependency map
3. Readiness gates
4. Enablement & assets
5. Channel activation
6. Release coordination
7. Launch monitoring
8. Post-launch learning

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate launchos` to materialize only those skill packages into a working directory.

## Handoffs
buildos, revenueos, brandos, customeros

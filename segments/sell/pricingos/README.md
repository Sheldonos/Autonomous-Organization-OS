# PricingOS

**Mission:** Design and continuously improve pricing, packaging, discounting, and monetization using evidence and guardrails.

## Operating loop
1. Value metric
2. Segmentation
3. Competitive benchmark
4. Economics
5. Package architecture
6. Price testing
7. Discount guardrails
8. Performance monitoring

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate pricingos` to materialize only those skill packages into a working directory.

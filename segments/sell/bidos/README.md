# BidOS

**Mission:** Find and win structured opportunities such as RFPs, RFIs, RFQs, grants, prizes, and procurement competitions.

## Operating loop
1. Opportunity intake
2. Eligibility & fit
3. Requirement extraction
4. Compliance matrix
5. Solution & win strategy
6. Pricing & approvals
7. Submission assembly
8. Submission & follow-up
9. Award transition

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate bidos` to materialize only those skill packages into a working directory.

## Handoffs
dealos, researchos, pricingos, legalos, grantos

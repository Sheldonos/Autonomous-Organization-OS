# GrantOS

**Mission:** Discover, qualify, assemble, submit, manage, and report on grant opportunities.

## Operating loop
1. Opportunity discovery
2. Eligibility
3. Funder research
4. Requirement matrix
5. Narrative & budget
6. Internal approvals
7. Submission
8. Award setup
9. Compliance reporting

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate grantos` to materialize only those skill packages into a working directory.

bidos, researchos, fundraiseos, complianceos

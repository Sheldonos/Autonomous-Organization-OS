# DealOS

**Mission:** Discover, qualify, pursue, negotiate, close, and operationalize profitable commercial opportunities.

## Operating loop
1. Opportunity discovery
2. Qualification & scoring
3. Account research
4. Offer & solution fit
5. Outreach / response
6. Proposal & negotiation
7. Approval & close
8. Billing, relationship memory & expansion

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate dealos` to materialize only those skill packages into a working directory.

## Handoffs
researchos, bidos, revenueos, consultingos, legalos, executiveos

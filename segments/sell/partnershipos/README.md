## Operating loop
1. Partner thesis
2. Partner universe
3. Fit & value exchange
4. Outreach
5. Joint plan
6. Agreement & enablement
7. Co-sell execution
8. Partner performance & renewal

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate partnershipos` to materialize only those skill packages into a working directory.

# RevenueOS

**Mission:** Operate the full revenue engine from ICP and demand through sales, onboarding, retention, and expansion.

## Operating loop
1. Market & ICP
2. Positioning & offers
3. Demand generation
4. Lead/account intelligence
5. Pipeline execution
6. Onboarding
7. Customer success
8. Expansion & retention
9. Revenue learning loop

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate revenueos` to materialize only those skill packages into a working directory.

# CustomerOS

**Mission:** Coordinate customer onboarding, service, success, adoption, retention, renewal, and expansion.

## Operating loop
1. Customer intake
2. Onboarding
3. Adoption plan
4. Health monitoring
5. Support & issue resolution
6. Value realization
7. Renewal
8. Expansion & advocacy

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate customeros` to materialize only those skill packages into a working directory.

## Handoffs
revenueos, dealos, buildos, customeros

# UniversityOS

**Mission:** Operate higher-education academic and learner workflows across programs, courses, advising, projects, credentials, and outcomes.

## Operating loop
1. Program architecture
2. Admissions/intake handoff
3. Course & faculty planning
4. Learning delivery
5. Assessment & advising
6. Projects/research
7. Credentialing
8. Career/outcomes

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate universityos` to materialize only those skill packages into a working directory.

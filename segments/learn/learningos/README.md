# LearningOS

**Mission:** Provide the shared lifelong-learning and adaptive mastery layer across school, university, workforce, and self-directed learning.

## Operating loop
1. Learner graph
2. Goal/construct map
3. Adaptive path
4. Learning interaction
5. Evidence capture
6. Mastery inference
7. Intervention
8. Credential & next-step routing

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate learningos` to materialize only those skill packages into a working directory.

## Handoffs
educationos, universityos, workforceos, talentos

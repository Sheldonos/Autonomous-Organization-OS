# AcceleratorOS

**Mission:** Operate venture or talent accelerators from cohort sourcing through curriculum, mentorship, milestones, demo, and alumni outcomes.

## Operating loop
1. Program thesis
2. Cohort sourcing
3. Selection
4. Curriculum & mentor matching
5. Milestones
6. Office hours & interventions
7. Demo/placement
8. Alumni outcomes

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate acceleratoros` to materialize only those skill packages into a working directory.

## Handoffs
ventureos, learningos, dealos, fundraiseos

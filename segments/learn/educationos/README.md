# EducationOS

**Mission:** Operate personalized education from curriculum and instruction through assessment, mastery, safety, credentialing, and progression.

## Operating loop
1. Learner/context intake
2. Curriculum mapping
3. Learning path
4. Instruction
5. Practice & feedback
6. Assessment
7. Mastery update
8. Credential/evidence
9. Progression & safety review

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate educationos` to materialize only those skill packages into a working directory.

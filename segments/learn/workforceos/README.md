# WorkforceOS

**Mission:** Continuously map employee capabilities to roles, learning, projects, credentials, and internal mobility.

## Operating loop
1. Role/capability graph
2. Employee skill evidence
3. Gap analysis
4. Learning plan
5. Practice/project placement
6. Assessment
7. Credential
8. Mobility & workforce feedback

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate workforceos` to materialize only those skill packages into a working directory.

## Handoffs
talentos, learningos, recruitos

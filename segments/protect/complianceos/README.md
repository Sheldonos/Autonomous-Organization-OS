# ComplianceOS

**Mission:** Translate obligations into controls, evidence, monitoring, remediation, attestations, and audit-ready reporting.

## Operating loop
1. Obligation inventory
2. Control mapping
3. Evidence plan
4. Continuous monitoring
5. Exception detection
6. Remediation
7. Testing/attestation
8. Audit package

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate complianceos` to materialize only those skill packages into a working directory.

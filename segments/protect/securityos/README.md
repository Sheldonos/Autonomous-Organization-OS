# SecurityOS

**Mission:** Continuously reduce cyber risk through asset visibility, detection, investigation, remediation, validation, and governance.

## Operating loop
1. Asset & identity inventory
2. Attack surface & risk
3. Detection engineering
4. Monitoring
5. Investigation
6. Containment/remediation
7. Validation
8. Control evidence & learning

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate securityos` to materialize only those skill packages into a working directory.

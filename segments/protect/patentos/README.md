# PatentOS

**Mission:** Manage invention intake, prior-art and landscape research, prosecution support, portfolio intelligence, and IP obligations.

## Operating loop
1. Invention intake
2. Prior-art research
3. Claim/landscape analysis
4. Disclosure package
5. Counsel handoff
6. Prosecution tracking
7. Portfolio review
8. License/renewal obligations

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate patentos` to materialize only those skill packages into a working directory.

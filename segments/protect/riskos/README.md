# RiskOS

**Mission:** Maintain enterprise risk intelligence, scenarios, treatment plans, controls, ownership, and escalation.

## Operating loop
1. Risk identification
2. Assessment
3. Scenario analysis
4. Treatment decision
5. Control assignment
6. Monitoring
7. Escalation
8. Review & closure

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate riskos` to materialize only those skill packages into a working directory.

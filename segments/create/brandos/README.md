# BrandOS

**Mission:** Maintain brand positioning, identity, messaging, asset governance, campaigns, and brand performance.

## Operating loop
1. Brand intelligence
2. Positioning
3. Messaging system
4. Identity & asset governance
5. Campaign briefs
6. Creative QA
7. Distribution
8. Brand measurement

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate brandos` to materialize only those skill packages into a working directory.

## Handoffs
mediaos, creatoros, revenueos, agencyos

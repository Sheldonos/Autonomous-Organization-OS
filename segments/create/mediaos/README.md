# MediaOS

**Mission:** Operate a publication from signal detection and reporting through multi-format distribution, audience learning, and monetization.

## Operating loop
1. Signal detection
2. Editorial prioritization
3. Research & fact check
4. Story construction
5. Format adaptation
6. Publishing
7. Distribution
8. Audience analytics
9. Monetization learning

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate mediaos` to materialize only those skill packages into a working directory.

## Handoffs
researchos, brandos, creatoros, revenueos

# CreatorOS

**Mission:** Turn a creator, artist, expert, or audience into a coordinated content, partnership, product, community, and revenue business.

## Operating loop
1. Identity & audience intelligence
2. Editorial/content system
3. Production
4. Publishing
5. Audience growth
6. Partnerships
7. Products/commerce
8. Community
9. Revenue analytics

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate creatoros` to materialize only those skill packages into a working directory.

## Handoffs
mediaos, brandos, commerceos, dealos, revenueos

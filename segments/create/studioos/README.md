# StudioOS

**Mission:** Operate audiovisual and entertainment production from concept and IP through production, post, distribution, and franchise learning.

## Operating loop
1. Concept/IP
2. Development
3. Script/story
4. Pre-production
5. Production
6. Post-production
7. Quality review
8. Distribution
9. Audience/franchise learning

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate studioos` to materialize only those skill packages into a working directory.

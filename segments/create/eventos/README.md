# EventOS

**Mission:** Design and operate events from concept and economics through speakers, sponsors, attendees, production, and post-event monetization.

## Operating loop
1. Event concept & economics
2. Venue/date
3. Program & speakers
4. Sponsors & partners
5. Audience acquisition
6. Production plan
7. Live operations
8. Follow-up & content
9. Event P&L learning

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate eventos` to materialize only those skill packages into a working directory.

## Handoffs
dealos, brandos, mediaos, revenueos

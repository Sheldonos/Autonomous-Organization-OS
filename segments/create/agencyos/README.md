# AgencyOS

**Mission:** Run a multi-client creative, marketing, product, or technology agency from pipeline through delivery, margin, and retention.

## Operating loop
1. Pipeline & qualification
2. Discovery
3. Scope & pricing
4. Staffing
5. Delivery
6. Client review
7. Billing & margin
8. Retention & expansion

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate agencyos` to materialize only those skill packages into a working directory.

## Handoffs
dealos, consultingos, pmoos, brandos, revenueos

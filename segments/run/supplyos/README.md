# SupplyOS

**Mission:** Coordinate demand, sourcing, supply planning, inventory, logistics, exceptions, and service levels.

## Operating loop
1. Demand signal
2. Supply plan
3. Sourcing alignment
4. Inventory policy
5. Logistics plan
6. Execution
7. Exception control tower
8. Service & cost optimization

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate supplyos` to materialize only those skill packages into a working directory.

## Handoffs
procureos, vendoros, commerceos, riskos

# ProcureOS

**Mission:** Turn internal needs into governed sourcing, competitive procurement, negotiation, purchase, and supplier performance.

## Operating loop
1. Need & specification
2. Spend analysis
3. Supplier discovery
4. RFI/RFP
5. Evaluation
6. Risk & negotiation
7. Contract & purchase
8. Supplier performance
9. Renewal

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate procureos` to materialize only those skill packages into a working directory.

## Handoffs
vendoros, legalos, riskos, supplyos

# TalentOS

**Mission:** Align workforce capabilities to strategy through planning, mobility, performance, development, automation, and hiring decisions.

## Operating loop
1. Strategic workforce demand
2. Capability inventory
3. Gap analysis
4. Build/buy/borrow/automate decision
5. Development & mobility
6. Performance
7. Succession
8. Workforce outcomes

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate talentos` to materialize only those skill packages into a working directory.

## Handoffs
recruitos, workforceos, enterpriseos

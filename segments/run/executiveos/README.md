# ExecutiveOS

**Mission:** Maintain executive situational awareness, decision queues, delegation, follow-through, and organizational memory.

## Operating loop
1. Overnight/periodic sensing
2. Priority triage
3. Decision queue
4. Meeting intelligence
5. Delegation
6. Follow-up
7. Risk & commitment tracking
8. Executive brief

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate executiveos` to materialize only those skill packages into a working directory.

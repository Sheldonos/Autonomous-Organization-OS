# EnterpriseOS

**Mission:** Act as the federation control plane that senses organizational state, decomposes objectives, routes work, governs execution, and measures outcomes.

## Operating loop
1. Organizational sensing
2. Objective decomposition
3. Capability & gap mapping
4. Pocket/team routing
5. Plan & approval graph
6. Execution coordination
7. Read-back verification
8. Outcome telemetry
9. Continuous improvement

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate enterpriseos` to materialize only those skill packages into a working directory.

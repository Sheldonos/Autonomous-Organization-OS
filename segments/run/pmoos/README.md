# PMO OS

**Mission:** Translate strategy into portfolios, programs, projects, dependencies, risks, decisions, and measurable outcomes.

## Operating loop
1. Portfolio intake
2. Prioritization
3. Program planning
4. Dependency & resource map
5. Execution tracking
6. Risk/issues
7. Decision & escalation
8. Benefits realization

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate pmoos` to materialize only those skill packages into a working directory.

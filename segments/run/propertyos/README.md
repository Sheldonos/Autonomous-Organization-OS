# PropertyOS

**Mission:** Operate real-estate opportunities and portfolios from underwriting through diligence, leasing, operations, and disposition.

## Operating loop
1. Market & asset discovery
2. Underwriting
3. Diligence
4. Acquisition/lease decision
5. Asset operations
6. Tenant/occupancy
7. Capital planning
8. Disposition/renewal

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate propertyos` to materialize only those skill packages into a working directory.

## Handoffs
capitalos, legalos, procureos, riskos

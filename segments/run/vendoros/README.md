# VendorOS

**Mission:** Manage third-party vendors from onboarding and risk through performance, obligations, renewal, and exit.

## Operating loop
1. Vendor intake
2. Due diligence
3. Onboarding
4. Obligation & SLA setup
5. Performance monitoring
6. Risk review
7. Renewal decision
8. Exit & knowledge transfer

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate vendoros` to materialize only those skill packages into a working directory.

## Handoffs
procureos, legalos, riskos

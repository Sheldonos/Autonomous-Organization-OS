# RecruitOS

**Mission:** Operate recruiting from demand and sourcing through assessment, offer, onboarding transition, and funnel learning.

## Operating loop
1. Requisition
2. Sourcing strategy
3. Candidate discovery
4. Screening
5. Assessment
6. Interview loop
7. Offer approvals
8. Onboarding handoff
9. Funnel analytics

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate recruitos` to materialize only those skill packages into a working directory.

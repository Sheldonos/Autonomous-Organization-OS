# BoardOS

**Mission:** Prepare board governance, decision materials, action tracking, risk visibility, and institutional memory.

## Operating loop
1. Agenda & governance calendar
2. Information request
3. Board packet
4. Risk & performance synthesis
5. Decision preparation
6. Meeting/minutes
7. Action tracking
8. Governance archive

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate boardos` to materialize only those skill packages into a working directory.

executiveos, enterpriseos, riskos, capitalos

# FranchiseOS

**Mission:** Design, sell, launch, govern, and optimize a repeatable franchise operating network.

## Operating loop
1. Franchise model
2. Unit economics
3. Territory strategy
4. Franchisee qualification
5. Agreement
6. Site/opening
7. Operating compliance
8. Performance & expansion

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate franchiseos` to materialize only those skill packages into a working directory.

## Handoffs
dealos, brandos, propertyos, legalos, commerceos

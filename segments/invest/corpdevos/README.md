# CorpDevOS

**Mission:** Evaluate and execute build/buy/partner/invest strategies for corporate growth and strategic capability acquisition.

## Operating loop
1. Strategic gap
2. Build/buy/partner/invest analysis
3. Target universe
4. Screening
5. Diligence
6. Synergy & valuation
7. Executive decision
8. Transaction/partner handoff

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate corpdevos` to materialize only those skill packages into a working directory.

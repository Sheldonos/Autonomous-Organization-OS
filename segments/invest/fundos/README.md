# FundOS

**Mission:** Operate fund intelligence and administration around mandate, pipeline, portfolio, reporting, and governance.

## Operating loop
1. Mandate & policy
2. Pipeline
3. Diligence & IC
4. Portfolio construction
5. Monitoring
6. Valuation/NAV support
7. LP reporting
8. Governance & audit

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate fundos` to materialize only those skill packages into a working directory.

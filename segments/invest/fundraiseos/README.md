# FundraiseOS

**Mission:** Plan and execute capital raising from investor thesis and targeting through diligence, commitments, and relationship management.

## Operating loop
1. Raise strategy
2. Investor universe
3. Materials & data room
4. Outreach
5. Meeting pipeline
6. Diligence responses
7. Terms & commitments
8. Close & investor relations

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate fundraiseos` to materialize only those skill packages into a working directory.

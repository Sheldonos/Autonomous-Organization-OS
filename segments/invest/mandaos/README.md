# M&A OS

**Mission:** Manage merger and acquisition workflows from target discovery through diligence, transaction planning, and integration handoff.

## Operating loop
1. Target discovery
2. Strategic screen
3. Approach & NDA
4. Diligence
5. Valuation & synergy
6. Risk & approvals
7. Transaction planning
8. Integration handoff

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate mandaos` to materialize only those skill packages into a working directory.

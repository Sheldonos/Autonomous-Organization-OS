# CapitalOS

**Mission:** Operate investment research and portfolio intelligence from thesis through diligence, IC decision, and monitoring.

## Operating loop
1. Mandate & thesis
2. Market screen
3. Company/asset research
4. Financial model
5. Diligence
6. Scenario & risk
7. IC memo
8. Portfolio monitoring

## Shared capability substrate
This pocket does not duplicate the entire skill corpus. `skill_routes.json` selects up to 120 high-relevance canonical skills from the 3,212-skill registry. Run `python aos.py hydrate capitalos` to materialize only those skill packages into a working directory.

researchos, riskos, corpdevos, fundos
